# PlatformIndependentNuGetPackages.Legacy.Tests

## Short description

Sdílené repo testů pro všechny balíčky ve sbírce PlatformIndependentNuGetPackages.Legacy. Každý balíček s testy má mít vlastní podsložku Balíček.Tests. Zatím obsahuje jen README.


Sdileny repo testu pro vsechny balicky v PlatformIndependentNuGetPackages.Legacy.
Kazdy balicek s testy dostane vlastni podslozku `<Balicek>.Tests` primo v tomhle repu
(stejna konvence jako PlatformIndependentNuGetPackages.Tests u pinp).
